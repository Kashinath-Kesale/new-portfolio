# 💼 Personal Portfolio | Kashinath Kesale

A personal portfolio website built with React.js and Tailwind CSS to showcase my projects, technical skills, experience, and contact details.

## 🌐 Live Demo

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-Visit_Portfolio-0284c7?style=for-the-badge&logo=vercel&logoColor=white)](https://kashinath-kesale-portfolio.vercel.app)

## ✨ Features

- 🌓 Dark and Light mode support with persistent preference
- 📱 Fully responsive design for desktop, tablet, and mobile
- ⚡ Smooth scroll navigation
- 📁 Project showcase with technical details and source code links
- 📋 Direct contact options with one-click copy functionality

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Icons & Typography:** React Icons, react-simple-typewriter
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Kashinath-Kesale/new-portfolio.git
cd new-portfolio

# Install dependencies
npm install

# Start development server
npm start
```

### Production Build

```bash
npm run build
```
